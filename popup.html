The processor measures 400 ms momentary and 3-second short-term K-weighted loudness. It attenuates quickly when audio gets loud and recovers slowly. Silence is not deliberately amplified. Peak limiting can prevent the output reaching the target. Output is estimated from input loudness and applied gain, not independently metered. This is an experimental leveller, not a certified loudness meter. Settings persist when capture stops; the graph resets.
